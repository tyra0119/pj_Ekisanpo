# エキさんぽ（公開用）

JR池袋駅と池袋の地下街を、人の目線で歩き回れるウェブアプリの公開用リポジトリです。
ソースは [tyra0119/Ekisanpo](https://github.com/tyra0119/Ekisanpo)（`npm run publish` で書き出したもの）。

- 公開ページ: https://tyra0119.github.io/pj_Ekisanpo/

出典: JR東日本「鉄道関連情報（GTFS-Pathways）」「構内地図データ」（JR東日本コンサルタンツ）公共交通オープンデータチャレンジ限定ライセンス ／ 3D都市モデル（Project PLATEAU）豊島区（2025年度） 国土交通省
